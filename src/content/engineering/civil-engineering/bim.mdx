# BIM & Digital Twins

Building Information Modeling (BIM) is a process for creating and managing digital representations of physical and functional characteristics of a facility.

## BIM Levels

| Level | Description |
|---|---|
| Level 0 | 2D CAD, no collaboration |
| Level 1 | 2D/3D CAD, shared data environment |
| Level 2 | Federated 3D models, discipline coordination |
| Level 3 | Fully integrated model (ISO 19650 aligned) |

## Key Standards

- **ISO 19650** — International BIM standard (organization and digitization of information)
- **PAS 1192** — UK BIM framework (now superseded by ISO 19650)
- **IFC (Industry Foundation Classes)** — Open file format for BIM data exchange

## Software

- **Autodesk Revit** — Industry-standard BIM authoring tool
- **Navisworks** — Model coordination and clash detection
- **BIM 360 / Autodesk Construction Cloud** — Cloud-based project delivery
