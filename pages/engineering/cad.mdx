# CAD & Drafting

Computer-Aided Design (CAD) is the use of software to create precise 2D drawings and 3D models for engineering and construction documentation.

## Fundamentals

### Drawing Standards
- **ISO 128** — Technical drawings — general principles of presentation
- **ISO 7200** — Title blocks
- Line weights, linetypes, and layer conventions

### AutoCAD Essentials
- Coordinate systems (WCS vs UCS)
- Object Snap (OSNAP) and precision drawing
- Layouts, viewports, and plotting
- External references (Xrefs) and block libraries

### Annotation
- Dimensions and tolerances
- Text styles and annotation scaling
- Leaders and multileaders

## File Formats

| Format | Use |
|---|---|
| `.dwg` | Native AutoCAD format |
| `.dxf` | Drawing Exchange Format — interoperability |
| `.pdf` | Issue for construction / review |
| `.ifc` | BIM interoperability |
